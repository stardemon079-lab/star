# Roblox Game Framework

A modular Lua framework for building monetizable Roblox games with minimal building skills.

## Core Systems

- **System Messages** - In-game notifications and chat system
- **Event System** - Trigger mechanics across your game
- **Player Management** - Data saving and stats tracking
- **Economy** - Currency, transactions, and rewards
- **Inventory** - Item management system
- **UI Framework** - Consistent UI components
- **Leaderboards** - Player ranking and progression
- **Configuration** - Easy game tuning without code changes

## Project Structure

```
src/
├── Services/          # Core game services
├── Systems/           # Game mechanics systems
├── UI/                # UI components
├── Config/            # Game configuration
└── Utilities/         # Helper functions
```

## Getting Started

1. Place these modules in **ServerScriptService** or **StarterPlayer > StarterCharacterScripts**
2. Customize config files for your game
3. Build your game logic on top of these systems
